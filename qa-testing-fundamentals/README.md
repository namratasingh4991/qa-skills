# qa-testing-fundamentals

Test strategy, risk analysis, test case design, and test planning skills for building comprehensive QA frameworks.

## Skills (8)

- **test-strategy** — Create a comprehensive test strategy framework
- **risk-analysis** — Risk-based testing approach and prioritization
- **test-case-design** — Design effective and maintainable test cases
- **test-plan** — Develop a detailed test plan with timelines and resources
- **exploratory-testing** — Structured exploratory testing approach
- **test-estimation** — Estimate testing effort and resource planning
- **test-data-strategy** — Plan test data requirements and generation
- **test-coverage-analysis** — Measure and optimize code/requirement coverage

## Commands (4)

- `/qa-testing-fundamentals:test-strategy` — Create a comprehensive test strategy
- `/qa-testing-fundamentals:test-plan` — Develop a detailed test plan
- `/qa-testing-fundamentals:risk-analysis` — Perform risk-based testing analysis
- `/qa-testing-fundamentals:test-coverage` — Analyze test coverage requirements

## Examples

Skills:
- `Create a test strategy for an enterprise SaaS product launch`
- `Identify high-risk areas in a payment processing system`
- `Design test cases for a user authentication flow`

Commands:
- `/qa-testing-fundamentals:test-strategy E-commerce platform with payment integration`
- `/qa-testing-fundamentals:risk-analysis High-risk: payment processing, user data`
- `/qa-testing-fundamentals:test-coverage Legacy codebase modernization project`
