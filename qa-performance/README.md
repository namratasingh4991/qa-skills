# qa-performance

Performance testing, load testing, stress testing, and optimization analysis skills.

## Skills (7)

- **perf-test-strategy** — Performance testing strategy and goals
- **load-testing-plan** — Design load testing scenarios
- **stress-testing** — Conduct stress testing
- **baseline-analysis** — Establish performance baselines
- **bottleneck-identification** — Identify performance bottlenecks
- **optimization-recommendations** — Performance optimization guidance
- **perf-monitoring** — Performance monitoring and alerting

## Commands (3)

- `/qa-performance:perf-testing` — Plan performance testing
- `/qa-performance:load-test` — Design load testing scenarios
- `/qa-performance:perf-analysis` — Analyze performance metrics

Commands:
