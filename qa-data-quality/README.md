# qa-data-quality

Data validation, ETL testing, data integrity, and analytics validation skills.

## Skills (6)

- **data-validation-strategy** — Data quality validation approach
- **etl-testing** — ETL pipeline testing
- **data-integrity** — Test data integrity and consistency
- **analytics-validation** — Validate analytics data
- **database-testing** — Database testing best practices
- **data-quality-metrics** — Define data quality KPIs

## Commands (3)

- `/qa-data-quality:data-validation` — Plan data quality testing
- `/qa-data-quality:etl-testing` — Test ETL pipelines
- `/qa-data-quality:analytics-validation` — Validate analytics data

## Examples

Skills:
- `Validate data integrity in customer records`
- `Test ETL data transformation`
- `Verify analytics reporting accuracy`

Commands:
- `/qa-data-quality:data-validation Customer data migration`
- `/qa-data-quality:etl-testing Data warehouse loading`
