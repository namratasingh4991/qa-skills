# Automation Framework Selection Skill

## Purpose
Select appropriate test automation framework based on technology stack and testing needs.

## When to Use
- Starting automation efforts
- Evaluating framework changes
- Technology stack decisions

## Framework Categories

### Web Automation
- **Selenium**: Cross-browser, widely adopted
- **Cypress**: Modern, fast feedback
- **Playwright**: Multi-browser, better API
- **Puppeteer**: Chrome/Chromium specific

### Mobile Automation
- **Appium**: Cross-platform mobile
- **XCUITest**: iOS automation
- **Espresso**: Android automation

### API Automation
- **RestAssured**: Java REST testing
- **Requests**: Python HTTP library
- **Postman/Newman**: REST API testing
- **GraphQL Testing Tools**: GraphQL-specific

### Desktop Automation
- **WinAppDriver**: Windows apps
- **TestComplete**: Cross-platform
- **UFT**: Enterprise automation

## Selection Criteria

1. **Technology Stack Compatibility**
2. **Team Expertise**
3. **Maintenance Burden**
4. **Scalability Needs**
5. **Reporting Requirements**
6. **Community Support**
7. **Cost Considerations**

## Usage Example

```
User: "Recommend automation framework for React SPA"

AI Response: [Recommends framework with]
- Technology alignment
- Pros/cons
- Implementation approach
- Setup requirements
```
